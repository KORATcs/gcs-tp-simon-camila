# Manual de usuario (v1.1)
1. Ingresar nombre y teléfono.
2. El campo Teléfono solo admite números (0-9). No se permiten letras, espacios ni símbolos.
3. Si el teléfono es inválido, se muestra "El teléfono solo debe contener números" y el cliente no se guarda.
4. Presionar "Guardar".
